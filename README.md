# 🎓 Student Management System

The **Student Management System** is a **console-based** application designed to efficiently manage student records for an educational institution. It enables users to perform CRUD (Create, Read, Update, Delete) operations on student data, including adding new students, updating and deleting records, and viewing details such as grades, courses, and personal information.  

This project is built using **Python** and leverages **file handling** for data storage instead of a database.

&nbsp;  
## ✨ Features  

📌 **Student Data Management:**  
- 📝 Add New Students
- ✏️ Update Student Information 
- ❌ Delete Student Records  
- 📄 View Student Details  

📌 **Data Storage & Retrieval:**  
- 📂 File Handling-Based Storage 
- 🔍 Search Students 

📌 **User-Friendly Console Interface:**  
- ⌨️ Interactive Menu 
- ⚡ Efficient operations
  
&nbsp;
## 🛠️ Built With  

- **Programming Language:** 🐍 Python  
- **Data Storage:** 📂 File Handling (Text Files)  
- **Concepts Used:** Functions, Loops, Exception Handling, File I/O, etc.

1. Clone the repository:  
   ```sh
   git clone https://github.com/your-username/Student-Management-System.git
   ```
2. Navigate to the project directory:  
   ```sh
   cd Student-Management-System
   ```
3. Run the application:  
   ```sh
   python main.py
   ```
